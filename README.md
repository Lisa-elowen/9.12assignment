# 稳面 · AI 压力面试教练

> 公网体验:https://9-12assignment-lwac.vercel.app/

> **16 小时项目挑战作品** —— 题目:做一个帮助本科生准备大厂实习面试 / 保研复试的"AI 模拟面试官"。
> 提交仓库:包含产品代码、挑战书、开发流程记录(Trellis)。

## 项目简介

准备面试的学生普遍面临:**找不到资深人士高频对练、得不到可执行的针对性反馈**。而更隐蔽的问题是——**"我知道答案,但在压力下没有表现出来。"**

稳面不是题库问答,而是一场**实时高压模拟面试 + 压力体检报告**:

- AI 面试官围绕你的简历动态追问,并且有**4 种性格**(温和引导 / 专业严谨 / 高压施压 / 好奇深挖)
- 答题途中会随机发动**真实世界才会发生的突发状况**:突然打断、突然换题、要求举例、质疑否定、长时间沉默、完全不会的题
- 全程采集压力信号并量化:
  - **愣神计时**:提问后犹豫超过阈值(压力模式 3s / 普通 5s)开始扣分,答题区实时提示
  - **语气词检测**:20+ 高频语气词字典,报告给出每个词的**具体替换建议**
  - **心率估算**:基于犹豫时长与压力信号的实时估算(峰值进报告)
- 面试结束后生成**完整评价体系**:
  - **六维能力雷达图**:表达稳定 / 逻辑组织 / 反应速度 / 压力恢复 / 内容深度 / 表达节奏(参考健身 App 能力图)
  - **压力曲线**:逐轮压力指数,定位被击穿的那一轮
  - **逻辑断裂点** / **恢复时间** / 崩溃点回放(模糊词高亮)
  - **针对性训练任务**:根据最弱维度生成下一次训练目标
- **应急锦囊**:首页内置突发状况应对手册(不会的题三步法、被质疑怎么接、突然换题怎么收尾……)

**核心闭环**:选场景 → 进面试舱(6 轮动态追问)→ 压力分析 → 六维体检报告 → 针对性训练。

## 运行方式

### 要求

- Node.js ≥ 18(开发环境为 v24)
- 浏览器推荐 Chrome / Edge(语音回答依赖 Web Speech API)

### 启动

```bash
cd pressurecoach
npm install
cp .env.example .env.local   # 填入 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL
npm run dev                  # 打开 http://localhost:3000
```

**不配 API Key 也能跑**:自动降级为内置脚本的演示模式(离线题目 + 本地语言分析引擎),核心闭环不受影响。

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://ark.cn-beijing.volces.com/api/v3`(豆包) |
| `LLM_API_KEY` | API 密钥 | — |
| `LLM_MODEL` | 模型名 | `doubao-1-5-pro-32k-250115` / `deepseek-chat` |

### 部署

```bash
cd pressurecoach
npm run build && npm start    # 生产模式
```

推荐 [Vercel](https://vercel.com) 一键部署(Next.js 原生支持,免费额度学生友好),部署时把上述三个环境变量填进项目配置即可。

## 技术栈说明

| 层 | 技术 | 说明 |
|---|---|---|
| 前端框架 | Next.js 15(App Router)+ React 19 | 全站客户端状态机:首页 → 配置 → 面试舱 → 报告 |
| 样式 | Tailwind CSS 4 | 侘寂风浅色纸感主题 + 朱红强调,自研设计 token(竖排文字 / 印章 / 禅圆开场 / 滚动显隐 / 逐字入场,零 emoji) |
| AI 面试官 | LLM API(OpenAI 兼容格式) | 服务端代理调用(`app/api/chat/route.ts`),支持豆包 / DeepSeek / Kimi 等;按人格注入系统提示词,JSON 模式输出 |
| 语音输入 | Web Speech API | 浏览器原生语音识别,免费实时转写,无需 ASR 服务 |
| 压力分析引擎 | 自研 TypeScript 模块(`lib/analysis.ts`) | 模糊词库(20+)、结构词库、犹豫时长、干预次数、逐轮退化检测、六维评分、压力曲线——纯本地计算,不依赖 LLM |
| 突发干预 | 自研干预引擎(`lib/interventions.ts`) | 打断 / 换题 / 举例 / 质疑 / 沉默 / 超纲,按模式与人格调触发概率 |
| 数据存储 | localStorage | MVP 无账号体系,训练历史本地保存(后续可换 Supabase) |
| 部署 | Vercel | Next.js 原生支持 |

## 设计取舍(刻意不做的)

- ❌ 摄像头情绪识别:隐私 + 不准确 + 成本高;语言与时间信号已能反映压力
- ❌ 题库 / 标准答案:市场已有大量工具,不是差异化价值
- ❌ 账号系统 / 社区 / 排行榜:非核心价值,MVP 用 localStorage
- ❌ 全岗位覆盖:先聚焦本科生面试一个高价值场景,做深做窄
